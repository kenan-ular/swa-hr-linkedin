# Derimod TalentX

Derimod İnsan ve Kültür · çalışan deneyimi sitesi (prototip v13).

## Bu klasörde
- `index.html` — sitenin tamamı (tek dosya).
- `staticwebapp.config.json` — Azure Static Web Apps güvenlik başlıkları.

## Güncelleme
1. GitHub'da bu depoda **Add file → Upload files** ile yeni `index.html` dosyasını sürükleyin.
2. **Commit changes** düğmesine basın.
3. **Actions** sekmesinde iş yeşile döndüğünde (2–3 dk) site güncellenmiş olur.

## Önemli
Bu sürüm prototiptir: veriler her kullanıcının kendi tarayıcısında tutulur, e-posta gönderilmez.
Gerçek aday ve çalışan verisi bu sürüme girilmemelidir.
